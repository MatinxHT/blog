题目：真空中有一无限长带电导线，其电荷线密度为。相距导线长度a处有一长为L的均匀带电棒AB，电荷量为Q，求AB棒的受力。

{{< image src="images/posts/1-e1586271199552.png" alt="1-e1586271199552" >}}

思路：微元法，先求场强分布，再求棒上的力元，再积分。

### 解：

###### 1.1、微元法求场强

如图所示，建立坐标

{{< image src="images/posts/3-e1586271158219.png" alt="3-e1586271158219" >}}

取带点导线上一点线元（P点）对X轴上任意一点（Q点）的电场强度为

{{< math display="true" >}}\vec{E}=\frac{1}{4\pi \varepsilon _{0}}\frac{\lambda l}{r^{2}}\vec{e_{r}}{{< /math >}}

看得出来电场应该是个对称场，看不出来别做了。现在要求的就是{{< math display="false" >}}\vec{E_{x}}(x){{< /math >}}
数学准备：

{{< math display="true" >}}\sin \varphi =\frac{l}{r}=\frac{1}{\csc \varphi },tan\varphi =\frac{x}{l}=\frac{1}{\cot \varphi }{{< /math >}}

推论：

{{< math display="true" >}}r=a\csc \varphi ,l=a\cot \varphi{{< /math >}}

物理准备：

{{< math display="true" >}}dq=\lambda dl,dl=acsc^{2}\varphi d\varphi {{< /math >}}

来了：

{{< math display="true" >}}\vec{E_{x}}=\int d\vec{E_{x}}=2\int_{\frac{\pi }{2}}^{0}\frac{\lambda \vec{i}}{4\pi \varepsilon _{0}x}\sin \varphi d\varphi =\frac{\lambda }{2\pi \varepsilon _{0}}\frac{1}{x}\vec{i}{{< /math >}}

###### 1.2、高斯定理求场强

如图所示，建立坐标

{{< image src="images/posts/2-e1586271263747.png" alt="2-e1586271263747" >}}

由高斯定理得：

{{< math display="true" >}}\oint_{s} \vec{E}d\vec{s}=\frac{\sum q_{i}}{\varepsilon _{0}}{{< /math >}}

取柱面坐标,闭合圆柱面为高斯面，采用图示的正方向，看得出来是对称场，可得：

{{< math display="true" >}}\oint_{s}\vec{E}(x)d\vec{s}=\frac{\lambda l }{\varepsilon _{0}}\Rightarrow \vec{E}(x)=\frac{\lambda }{2\pi \varepsilon _{0}}\frac{1}{x}\vec{i}{{< /math >}}

###### 2、求AB所受的力

{{< math display="true" >}}\vec{F}=\int \vec{E}(x)dq=\int_{a}^{a+L} \vec{E}(x)\frac{Q}{L}dx=\frac{\lambda Q}{2\pi \varepsilon _{0}L}\vec{i}\int_{a}^{a+L}\frac{1}{x}dx{{< /math >}}

故：

{{< math display="true" >}}\vec{F}=\frac{\lambda Q}{2\pi \varepsilon _{0}L}\ln (1+\frac{L}{a})\vec{i}{{< /math >}}
